# research-summarizer

Structured research summarization for Claude Code (and Codex, Gemini CLI, OpenClaw). Summarize academic papers, compare web articles and reports, extract properly formatted citations, and produce actionable research briefs — built for non-developer users.

## Install

```bash
claude plugin add mark-satterfield/research-summarizer
```

## Usage

The **research-summarizer** skill auto-activates when you ask to summarize a paper, compare multiple sources, extract citations, or build a structured research brief.

## What's inside

- **Skill:** `research-summarizer` — key-finding extraction, comparative analysis, and citation formatting.
- **Scripts:** `scripts/extract_citations.py`, `scripts/format_summary.py` (standard library only).
- **References:** `references/citation-formats.md`, `references/summary-templates.md`.
