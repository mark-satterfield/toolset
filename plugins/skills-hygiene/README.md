# Skills Hygiene

Manage Claude Code skill installations — deduplicate, promote, audit, internalize, and generalize skills across global and project levels.

## Install

```bash
claude plugin add mark-satterfield/skills-hygiene
```

## What's Included

- **Skill**: Auto-activating skill management with these operations:
  - `inventory` / `audit` — list and assess installed skills
  - `dedupe` — remove duplicate skill installations
  - `promote` / `internalize` — move skills between global and project scope
  - `generalize` — extract reusable patterns from project-specific skills
  - `protect` / `unprotect` — lock skills from modification
  - `update` / `reset` — refresh or restore skills
- **Reference**: `claude-skills-architecture.md` — skill system internals
