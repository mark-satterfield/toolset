# Engineering

25 advanced engineering agent skills covering agent design, RAG architecture, MCP servers, CI/CD pipelines, database design, observability, security auditing, release management, and platform ops.

## Install

```bash
claude plugin add mark-satterfield/engineering
```

## What's Included

- **25+ skills** including:
  - `agent-designer` — agent architecture and orchestration
  - `rag-architect` — RAG pipeline design
  - `mcp-server-builder` — MCP server scaffolding
  - `ci-cd-pipeline-builder` — CI/CD pipeline generation
  - `database-designer` — schema and migration design
  - `observability-designer` — logging, metrics, tracing
  - Security auditing, release management, platform ops, and more
- **Commands** directory for slash-command invocations
