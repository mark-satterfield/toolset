How it works

From raw data to a shipped model in three steps

The Northwind Platform handles the orchestration so your team can move from messy spreadsheets to a production endpoint without stitching tools together by hand.

  1. 01 Connect

    Connect your sources

    Point Northwind at your warehouse, object storage, or a CSV upload. Schema is inferred on ingest and column types are validated before a single row is processed.

  2. 02 Configure

    Configure the pipeline

    Pick a target metric and let the Acme AutoML engine sweep features and hyperparameters. Override any default from the visual editor or commit a config file to your repo.

  3. 03 Ship

    Ship to a live endpoint

    Promote the winning model to a versioned REST endpoint with one click. Rollouts are gradual, every prediction is logged, and rollback is a single command away.
