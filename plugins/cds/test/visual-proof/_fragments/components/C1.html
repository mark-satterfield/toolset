Buttons

Every button family inherits the §14.1 base — 40px min-height, 8px radius, color 0.1s / background 0.2s / box-shadow 0.2s transition, a :focus-visible ring, and a 50% disabled opacity with pointer events off. Each block below shows variants and the rest / hover / focus / disabled states side by side.

Primary button

§14

Conversion / commit action — the dominant button on its surface. Fill + label using --button-primary-bg / --button-primary-text. Hover paints a 1px outer shoulder ring in the fill color over 200ms. Inverts ground with the page mode.

Tertiary button

§14

Quietest affordance — inline or link-like. Border + label using --button-tertiary-border / --text-tertiary. Transparent fill, hairline border, link-glyph leading. Hover shifts text to --text-primary; border unchanged.

Brand button

§14

Destructive button

§14

Reserved for irreversible actions (delete, revoke). Destructive fill (--error-fill) + inverse label. Hover scales the button (scale(1.015)) rather than re-coloring — suppressed under reduced motion. Focus ring uses the destructive color, not the brand accent.
