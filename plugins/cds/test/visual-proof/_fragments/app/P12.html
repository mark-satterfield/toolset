Gmail

Connected · refreshed 2 days ago

Connect Gmail to the agent to quickly find important email threads, draft replies, and triage your inbox. The agent reads only the messages it needs to answer a request and never sends or deletes anything without an explicit policy below.

Tool permissions

Choose when the agent is allowed to use these tools.

✓ Always allow ! Needs approval ✕ Never allow
Read-only tools 8 ✓ Always allow

  • Read thread

    Retrieves a specific email thread from the authenticated user's Gmail account.

  • Search messages

    Searches the mailbox using Gmail query syntax and returns matching message metadata.

  • List labels

    Returns the set of system and user-created labels available on the account.

  • Get attachment

    Downloads a single attachment from a message by its attachment identifier.

  • List drafts

    Lists draft messages saved in the account, newest first.

Write/delete tools 9 ! Needs approval

  • Send message

    Sends a composed email to one or more recipients from the connected account.

  • Create draft

    Saves a new draft message without sending it, returning the draft identifier.

  • Modify labels

    Adds or removes labels on a message, including archiving and marking as read.

  • Trash message

    Moves a message to Trash, where it is permanently deleted after 30 days.

Changes apply to every new agent run. Existing runs keep the policy they started with.
