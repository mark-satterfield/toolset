Visual proof suite

This is a visual proof / smoke-test gallery for the cds plugin. Every fragment on the linked pages was generated from the fixture design tokens in setup/customizable-design-elements.yaml and rendered against the shared styles/design-system.css. Flip the theme switcher above to confirm that every shape, surface, and component re-skins coherently across all seven themes — the theme contract is data-theme="<key>" on document.documentElement.
