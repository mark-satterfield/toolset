# Shape selection — T2 Trust Strip

The pick is driven by logo count: a large set scrolls as a marquee, a small set sits as a static grid. T2's items are logos only by definition, so `item_count` is the sole branching signal. Candidates are tried in order (primary, then alternates, then `default`) against the page constraints; if every candidate is rejected, the composer falls back to agent-generated layout and records that in the decisions sidecar.
