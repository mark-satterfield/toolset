# Shape selection — T13 Resource Directory

Items carrying source-type tags resolve to resource-grid, with tagged-card-grid as the alternate. Candidates are tried in order (primary, then alternates, then `default`) against the page constraints; if every candidate is rejected, the composer falls back to agent-generated layout and records that in the decisions sidecar.
