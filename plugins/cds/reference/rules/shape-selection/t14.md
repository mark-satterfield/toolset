# Shape selection — T14 Cross-Promo

Both formats resolve to banner-strip as a standalone Section. An event/register card with thumbnail may instead embed inside T10 — a composition choice declared in the T14 Section's `composition_notes`, not a shape this rule can pick. Candidates are tried in order (primary, then alternates, then `default`) against the page constraints; if every candidate is rejected, the composer falls back to agent-generated layout and records that in the decisions sidecar.
