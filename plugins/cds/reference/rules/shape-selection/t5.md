# Shape selection — T5 Workflow / Process

Three steps is the canonical horizontal numbered-steps read; any other count tabs the steps instead, with numbered-steps in its vertical variant as the alternate (a vertical numbered list reads at any count). A step set that fits neither candidate may instead split into two consecutive T5 Sections — that is a composition note on the T5 Section, not a shape in this table. Candidates are tried in order (primary, then alternates, then `default`) against the page constraints; if every candidate is rejected, the composer falls back to agent-generated layout and records that in the decisions sidecar.
