# Shape selection — T6 Use-Case Routing

A small role- or discipline-tagged set reads as a tagged grid; five or more categories that each carry sub-items spread into tag columns. Candidates are tried in order (primary, then alternates, then `default`) against the page constraints; if every candidate is rejected, the composer falls back to agent-generated layout and records that in the decisions sidecar.
