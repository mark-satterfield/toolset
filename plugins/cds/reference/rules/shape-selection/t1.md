# Shape selection — T1 Hero

The hero's pick is driven entirely by the visual the content supplies. Candidates are tried in order (primary, then alternates, then `default`) against the page constraints; if every candidate is rejected, the composer falls back to agent-generated layout and records that in the decisions sidecar.
