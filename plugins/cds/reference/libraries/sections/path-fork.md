# Path Fork

Binary fork in the funnel: self-serve versus assisted. `item_count` is 2 by definition — the fork presents exactly two paths. `emphasis` names how the two paths relate: `balanced` peers, a `sequential` reading of one band after another, or an attribute-by-attribute `contrast`.

The Shape pick consults `item_count` and `emphasis` via `rules/shape-selection/path-fork.md`.
