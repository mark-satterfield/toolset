# my-editor

Personal editing and writing-style toolkit.

## Install

```bash
claude plugin add mark-satterfield/my-editor
```

## Bundled Skills

- **adhd-edit** — Structural editing for long-form drafts with analyze,
  suggest, and rearrange modes.
- **my-style** — On-demand writing style skill that encodes Mark's voice,
  language, and rhetorical patterns.
