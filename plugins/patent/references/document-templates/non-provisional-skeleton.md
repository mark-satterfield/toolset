## Drawings (filed separately, 37 CFR 1.84)

To be supplied as black-and-white line drawings on 8.5×11" or A4 sheets, each figure numbered and described in the brief description of drawings.

## Filing checklist

- [ ] Application Data Sheet (ADS, Form AIA/14)
- [ ] Specification (this document, formatted per 37 CFR 1.52)
- [ ] Claims (separated section, numbered consecutively)
- [ ] Drawings (per 37 CFR 1.84)
- [ ] Abstract (separate sheet, ≤150 words)
- [ ] Oath or Declaration (Form AIA/01)
- [ ] Information Disclosure Statement (IDS) — see `ids-template.md`
- [ ] Filing fee (entity-dependent)
- [ ] Search fee
- [ ] Examination fee

(All forms available at https://www.uspto.gov/patents/basics/types-patent-applications/forms.)

## Fee structure (verify current at USPTO fee schedule)

- Basic filing fee: ~$320 (large) / ~$160 (small) / ~$65 (micro)
- Search fee: ~$700 (large) / ~$350 (small) / ~$175 (micro)
- Examination fee: ~$800 (large) / ~$400 (small) / ~$200 (micro)
- Total: ~$1,820 (large) / ~$910 (small) / ~$440 (micro)

Excess claim fees apply for >20 total claims or >3 independent claims.
