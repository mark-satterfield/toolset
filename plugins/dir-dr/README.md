# Directory Doctor

Builds a semantic model of any directory, detects structural problems, naming violations, stale content, and plans safe restructures with executable migration scripts.

## Install

```bash
claude plugin add mark-satterfield/dir-dr
```

## What's Included

- **Skill**: Auto-activating directory analysis and restructuring
- **Reference**: `categories.md` — semantic classification rules for directory contents
