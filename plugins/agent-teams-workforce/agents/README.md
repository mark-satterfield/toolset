# Agents

Place generated agent definitions here.

The source roster is `../references/sdlc-agent-roster.csv`. Each row should become one agent definition unless the role is better represented as a command-only workflow.

Suggested naming:

- File name: roster `Name` column, for example `ss-master-orchestrator.md`.
- Agent name: same as the roster `Name` column.
- Description: derive from `Purpose`, `Primary Role(s)`, `SDLC Phases`, and `Specializations`.
- Tools: derive from `Recommended Tools` and enforce `Restrictions`.
