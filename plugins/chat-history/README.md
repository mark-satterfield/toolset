# Chat History

Extract and organize Claude Code session history into a project `.chats` directory. Captures both user and assistant sides.

## Install

```bash
claude plugin add mark-satterfield/chat-history
```

## What's Included

- **Skill**: Auto-activating skill for session history extraction
- **Script**: `backfill_chat_history.py` — backfills past sessions into `.chats/`
