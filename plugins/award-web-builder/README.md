# award-web-builder

Award-tier website builder for Claude Code. A single design agent — **web-artisan** — plus a deep library of design skills for building Webby/Awwwards-quality web surfaces with strong design-system integration, brand compliance, and accessibility.

## Install

```bash
claude plugin add mark-satterfield/award-web-builder
```

## Usage

Start an interactive design session:

```
/award-web-builder:design [topic or question]
```

This spawns **web-artisan** in conversational mode — use it for anything about how a web surface looks, feels, moves, or is structured: pages, components, design systems and tokens, brand identity, visual direction, animation, Figma workflows, glassmorphism, and accessibility.

## What's inside

- **Agent:** `web-artisan` — the design specialist that does the work.
- **Command:** `/award-web-builder:design` — orchestrates an interactive session with web-artisan.
- **Skills:** focused design capabilities, including `creative-director`, `strategist`, `systems-architect`, `flow-designer`, `ui-typography`, `ux-onboarding`, `design-audit`, `handoff-specialist`, `liquid-glass` / `glassify`, `emil-design-eng`, `bencium-innovative-ux-designer`, and `philosopher`.
